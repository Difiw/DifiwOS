# Правила дизайна и анимаций Difiw Desktop

Все значения живут в одном месте — `src/difiw-desktop/tokens.hpp`. Новый размер, цвет или время добавляется туда,
а не в код отрисовки.

## Язык интерфейса
* тёмный графит (`kGraphite900..500`), холодные акценты: синий `kAccentBlue`, бирюзовый `kAccentTeal`, фиолетовый `kAccentViolet`;
* полупрозрачные «стеклянные» панели (`glass()`): заранее размытая копия обоев + графитовая вуаль (`kGlassTint`),
  тонкая светлая граница и верхний блик, мягкая тень; **настоящее размытие каждого кадра не делается** (дорого без GPU);
* большие радиусы: окна 14, панели 22, плавающая капсула 28, значки 14 (логические пиксели × масштаб интерфейса);
* никаких ярких радуг: световая палитра — только синий → бирюзовый → фиолетовый (`glow_color`);
* свой знак **D** (рисуется кодом: левая стойка, верх, низ и полукруг), без логотипов чужих систем;
* обои — отдельный слой; панель, окна и меню рисуются поверх и не «запекаются» в фон.

## Нижняя панель
* компактная плавающая капсула, не на всю ширину; D строго по центру;
* слева — только **запущенные пользователем приложения с окном**: значок, индикатор (точка — работает, длинная
  «таблетка» — активное окно), число окон при нескольких; незапущенные, службы и фоновые процессы здесь не показываются;
* при нехватке места значки сохраняют размер, появляются стрелки, прокрутка плавная (колесо над панелью тоже);
* справа — системная область: фоновые задачи (со счётчиком), сеть, звук, батарея (если есть), раскладка, часы/дата, уведомления.

## Всплывающие панели
Открываются **над своей кнопкой** (`place_popup`): центр по кнопке, ограничение по краям экрана, при нехватке места сверху —
высота уменьшается, а не панель «улетает». Вырастают из кнопки (масштаб 0.3 → 1, `kAnimPopup`), при закрытии возвращаются.
Нижний «носик» указывает на источник. Клик вне панели закрывает её; Esc — верхнюю.

## Анимации (`tokens.hpp`, «motion»)
| Событие | Что происходит | Время |
|---|---|---|
| наведение на значок | поднимается на `kHoverLift`, растёт до `kHoverScale`, по границе бежит свет (синий→бирюзовый→фиолетовый), соседи получают слабое отражённое свечение | `kAnimHover` |
| нажатие | значок сжимается до `kPressScale` и возвращается | `kAnimPress` |
| открытие/закрытие панели | рост из кнопки / обратно, содержимое проявляется | `kAnimPopup` |
| открытие окна | небольшой подъём и проявление | `kAnimWindow` |
Анимации считаются по времени (не по числу кадров), перерисовка — только когда что-то меняется или идёт анимация.

## Настройки доступности (меню D → «Параметры», `/etc/difiw/desktop.conf`)
* **Меньше движения** — все анимации отключаются, световая палитра «замораживается»; проверено: картинка неподвижна;
* **Прозрачность выкл** — панели становятся непрозрачным графитом (`kGlassTintOpaque`);
* **Масштаб** 100% / 200%: размеры и шрифт; расположение подстраивается под экран (системная область сжимается);
* язык интерфейса RU/EN; раскладка клавиатуры Alt+Shift;
* состояние не передаётся только цветом: активное окно — другая форма индикатора, критический процесс — значок замка и
  текст, выбор — рамка; видимый фокус клавиатуры в меню — контур;
* клавиатура: Super — меню D, стрелки/Enter/Tab/поиск в меню, Alt+Tab — окна, Alt+F4 — закрыть, Esc — закрыть панель.

## Ограничения шрифта
Растровый PSF 8x16 (латиница + кириллица). Заголовки и подписи используют его же; крупный текст — целочисленное
увеличение. Красивый векторный шрифт — задача следующего этапа.
