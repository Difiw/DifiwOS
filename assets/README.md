# Assets

- `wallpaper.ppm.gz` - default Difiw OS wallpaper, 1280x720 raw P6 PPM, gzip-compressed. Derived from the wallpaper
  image supplied by the project owner. It is unpacked to `/usr/share/difiw/wallpaper.ppm` by the build and scaled
  ("cover") to the screen by the desktop. Replace the file to change the default wallpaper.
