# Результаты проверки Difiw Desktop 0.4.0 (раздел 14 технического задания)

Все пункты проверены **настоящим запуском** ISO `difiw-os-0.4.0-x86_64.iso` в QEMU (автотесты `tests/desktop_qemu.py`,
`tests/desktop_variants.py`, запуск: `scripts/verify.sh`) и, где указано, в VirtualBox 7.2.22 на временной VM.
Дата: 2026-10-30. Итог `verify.sh`: **VERIFY: PASSED** (61 проверка оболочки на хосте, 39 QEMU-оболочка, 11 QEMU простая GUI,
39 рабочий стол, 9 варианты). SHA-256 образа: `7602c101805d7f6f9555da6cbde5376c6c4a5f0a3579e44bddda322c31ba932e`.

## Не проверено / ограничения
* Клики мыши в VirtualBox вручную не выполнялись (`VBoxManage` не вводит мышь); гость видит «VirtualBox USB Tablet»,
  клавиатурный сценарий в VirtualBox проверен; клики — только в QEMU.
* Реальное железо, UEFI, другие видеоконтроллеры, 16/32 bpp режимы.
* Качество анимаций оценивалось только по автоматическим проверкам и снимкам, не «на глаз» в реальном времени.
* Границы изоляции и чего нет — в [SECURITY.md](../SECURITY.md).
